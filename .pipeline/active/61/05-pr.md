## Summary

Adds full-screen functionality to the cat game with a toggle button and automatic canvas resizing. Moves score display from HTML into the canvas for cleaner UI. Converts pre-game UI (name field + start button) from DOM elements to canvas-drawn rendering, improving visual consistency across screen sizes.

## Changes

### `index.html`

- Wrapped `<canvas>` in `.canvas-wrapper` div for overlay positioning
- Added fullscreen toggle button (⛶) positioned top-right of canvas
- Removed `<div class="game-info">Score: 0</div>` element (score now drawn on canvas)
- Pre-game UI DOM elements (`#name-input`, `#start-btn`) kept in HTML but hidden via CSS

### `style.css`

- Added `.canvas-wrapper` styles: relative positioning, inline-block display
- Added `#fullscreenBtn` styles: absolute positioned, gold theme matching game UI, hover effect
- Removed `.game-info` CSS rules (no longer needed)
- Added CSS to hide pre-game DOM elements while keeping them functional for keyboard focus

### `js/game.js`

- Added element reference for fullscreen button
- Removed `scoreElement` variable and all related DOM updates (`scoreElement.innerText`)
- Implemented `toggleFullscreen()` function using Fullscreen API
- Added click handler with `stopPropagation()` to prevent canvas jump trigger
- Added `fullscreenchange` event listener (standard + Safari webkit-prefixed):
  - On enter: recomputes scale, clears render caches, resets game state if running
  - On exit: same recomputation logic for proper scaling restoration
- Feature detection: hides button on browsers without Fullscreen API support
- Score display moved to canvas `draw()` function: drawn in top-left corner above Speed counter
- Added `drawPreGameUI()` function: renders pre-game UI directly on canvas with sky gradient, grass background, name field (with blinking cursor), and start button
- Canvas click handler (`mousedown`): detects clicks on name field or start button using coordinate-based hit testing; focuses hidden input or starts game accordingly
- Touch support for mobile: added pre-game UI handling to existing `touchstart` listener
- Enter key handler: preserved on hidden input for keyboard-driven game start
- Animation loop: added initial `requestAnimationFrame(update)` at end of file, so canvas-drawn pre-game UI renders immediately on page load
