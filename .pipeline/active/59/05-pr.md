## Parallax Scrolling Layers for Grass, Trees, and Moon

### What Changed
Added 3 new parallax scrolling layers to the game's background:

1. **Background grass** — slower-moving decorative grass (🌿☘️🍀🎍🪴) at 70% foreground speed
2. **Trees** — semi-transparent trees (🌳🌲🌴🎋) at 35% speed, anchored near ground line
3. **Moon** — 🌖 positioned in sky area, scrolling at 20% speed

### Technical Details
- Each layer uses a pre-rendered offscreen canvas strip for efficient drawing (single `drawImage` per frame instead of multiple `fillText`)
- Moon draws directly via `fillText` (deviated from strip approach) because the shared render cache forces ground-level positioning, incompatible with sky-placed elements
- Draw order: gradient → moon → celestial objects → tree-strip → bg-grass-strip → fg-grass-strip → foreground elements

### Files Changed
- `js/game.js` — added 3 new init functions, 2 new emoji pools, speed ratio constants, offset tracking, and updated draw/update/reset/startGame/resize handlers
